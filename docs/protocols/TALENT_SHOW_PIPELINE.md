# Конвейер талант-шоу (Talent Show Pipeline) v1

**Принят спонсором:** 2026-11-26 · **Исполнитель:** zcode
**Принцип:** номер собирается из сцен-кусков; каждая сцена независимо
экзаменуется гейтгардами на trace (объективно, по квантованиям положения);
в финальный сценарий входят только пройденные сцены; публикация — только
после генеральной репетиции и слова спонсора.

## Сцены и посекундный сценарий финального номера (20.0 с)

| Сцена | Окно | Команды | Гейтгард (по trace) |
|---|---|---|---|
| S0 ENTRY | 0.0–2.0 | vx 0.6 → 0; голова-поклон | G0: пройдено ≥0.25 м за [0,1.2]; нет падения; z ≥ 0.05 |
| S1 LIE/HOLD | 2.0–5.5 | sit-флаг=1, держать | G1: доля z<0.085 в [2.2,5.4] ≥ 0.8; нет падения |
| S2 RISE | 5.5–7.0 | sit-флаг=0; кряк на вершине | G2: доля z≥0.105 в [6.0,6.9] ≥ 0.7; нет падения |
| S3 SONG | 7.0–13.0 | качели head yaw ±0.45 рад; ноты | G3: дрейф корня ≤0.12 м за окно; нет падения |
| S4 JUMPS | 13.0–16.0 | 5 пульсаций sit↔stand | G4: ≥2 провалов z<0.09 в окне; нет падения |
| S5 BOW | 16.0–20.0 | wheee (LT); глубокий поклон | G5: нет падения; финальная 1с стабильна (std z<0.01) |

Пороги поз из задачи: STAND_Z=0.115, SIT_Z=0.060; падение = z<0.045.

## Гейтгарды измеряются по trace
trace арены: (утки, шаги, TRACE_WIDTH), frame[0:7]=x,y,z,quat, [7:]=суставы.
Верификатор `scripts/duck/show_gates.py` проигрывает сцену через физику
(как судья), собирает trace, считает метрики окон, печатает PASS/FAIL.

## Конвейер
1. **Экзамен сцены**: show_gates.py --scene Sx --checkpoint <onnx/ckpt> → PASS/FAIL.
2. **Сборка**: сцены с PASS — в финальный timeline (сшивка команд подряд,
   каждая группа кейфрейма самодостаточна: пропущенная группа = нули).
3. **Генеральная**: полный 20с таймлайн через судью — все сцены разом.
4. **Режиссёрский просмотр**: клип рендером (свет+камеры+геом-группы).
5. **Слово спонсора** → публикация.

Сцена с FAIL не входит в сборку — номер сокращается до прошедших сцен
(деградация номера вместо несостоявшегося представления).
